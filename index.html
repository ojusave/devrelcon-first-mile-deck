FIELD IDENTIFIER ORDER

data-fmthennamethenid

Field events report focus, fill, blank, blur, or error. Abandonment is inferred later, not recorded as a motive.

NOT COLLECTED

  • No form values are stored or sent. Only empty or non-empty state is checked.
  • No DOM text, labels, placeholders, clipboard contents, query strings, or hashes.
  • Full URLs are not sent. Password and hidden fields are ignored.
  • A strict, closed schema rejects unknown event fields.
